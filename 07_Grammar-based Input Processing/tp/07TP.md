## Deskripsi
Fungsi toNumberArray berfungsi untuk memproses data dengan mengubah input berupa string yang dipisahkan tanda koma maupun kumpulan string dalam array menjadi array baru yang hanya berisi nilai numerik. Secara teknis, fungsi ini terlebih dahulu memeriksa jenis data input menggunakan operator typeof dan metode Array.isArray(). Jika input berupa string tunggal, misalnya "1, 2", maka string tersebut akan dipecah menggunakan metode .split(",") sehingga berubah menjadi array. Setelah format data dipastikan berbentuk array, fungsi memanfaatkan .map() bersama .trim() untuk menghapus spasi berlebih di setiap elemen, kemudian menggunakan .filter() untuk menghilangkan elemen kosong yang mungkin muncul, misalnya akibat penggunaan dua koma secara berurutan. Tahap berikutnya adalah mengubah setiap elemen teks menjadi tipe angka dengan Number(), di mana nilai yang tidak valid secara numerik, seperti "abc23", akan menghasilkan NaN. Pada tahap akhir, fungsi menyaring seluruh nilai NaN menggunakan .filter(angka => !Number.isNaN(angka)), sehingga output yang dihasilkan berupa array angka yang bersih dan siap digunakan.
